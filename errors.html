Error codes

When X1 can not do what you asked, its message ends with a small line such as Error code 15-2004. The first two digits are the command and the other four are the error; the first of those four tells the kind. A code is the same in English and Japanese, so you can send it to whoever runs the bot.

  • 1xxxyour input
  • 2xxxnot found / nothing to show
  • 3xxxan outside service failed
  • 4xxxrate limited
  • 5xxxnot allowed
  • 9xxxX1 itself failed
